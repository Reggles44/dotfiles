## Install

```bash
git clone git@github.com:Reggles44/dotfiles.git ~/dotfiles
~/dotfiles/install.sh
~/dotfiles/bootstrap.sh
```

### Arch packages

```bash
sudo pacman -S git networkmanager xclip mise
```

#### Applications

```bash
sudo pacman -S firefox discord
```

Steam
[Arch Linux Install Instructions](https://wiki.archlinux.org/title/Steam#Native_Steam_on_Linux)

sudo pacman -Sy steam
